# Mentorship flow v19

Student selects a domain -> sends request -> status is Pending -> faculty/admin receives a notification and sees it in Mentorship Requests -> faculty accepts/activates or rejects -> student sees the updated status -> when status is Active or Verified, both student and assigned faculty can open the protected chat -> messages are stored and notify the other participant.

Industry opportunities/jobs/internships/challenges remain visible through the student opportunity views; industry does not receive student/faculty learning navigation.
