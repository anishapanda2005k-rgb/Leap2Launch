LEAP2LAUNCH V26 — START HERE
============================

1. Extract the ZIP.
2. Open the folder that contains app.py and requirements.txt.
3. Double-click START_LEAP2LAUNCH_V26.bat. On first run it creates a local .venv and installs requirements.txt.
4. Open http://127.0.0.1:5000/.
5. To verify the running build, open http://127.0.0.1:5000/build-status.

If Windows blocks the script, open PowerShell in this folder and run:
    py -3.12 -m venv .venv
    .venv\Scripts\python.exe -m pip install -r requirements.txt
    .venv\Scripts\python.exe app.py

IMPORTANT
- Keep the database file and local uploads backed up.
- Do not delete database.db if you already have real local user data.
- If port 5000 is already in use, stop the older Flask terminal with Ctrl+C first.
- Real email OTP delivery needs valid SMTP environment settings; do not deploy with development secrets.
- External learning resources open on official provider sites. Certificate, exam, fee and eligibility terms can change; check the provider page.
- The external directory is a curated starting catalogue, not a claim that every individual course worldwide is already indexed.
